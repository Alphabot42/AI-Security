# Evidence provenance

The CSV files here are transcribed programmatically from HTML tables stored
in the executed notebook 04 supplied after the Cube-AI run. They are summaries,
not reconstructed per-source verification results. The original notebook
SHA-256 and the publication-copy hashes are in notebook_provenance.json.
Displayed scores and rates retain the precision actually present in the source.
No exact model threshold is inferred from a rounded notebook table.

The complete same_environment_results.json, fresh_environment_results.json,
qa_report.json, exported checkpoints and verification inputs must be collected
from the successful Cube-AI run before the frozen-runtime release is complete.
Publication preparation and successful technical reproduction are separate states.
