# Evidence provenance

The CSV files here are transcribed programmatically from HTML tables stored
in the executed notebook 04 supplied after the lab run. They are summaries,
not reconstructed per-source verification results. The original notebook
SHA-256 and the publication-copy hashes are in notebook_provenance.json.
Displayed scores and rates retain the precision actually present in the source.
No exact model threshold is inferred from a rounded notebook table.

The [complete V1 artifact evidence](quishing_v1/README.md) now includes the
original same_environment_results.json, fresh_environment_results.json and
qa_report.json. The frozen models and inputs are in [models/quishing_v1](../models/quishing_v1/).
The [independent artifact review](quishing_v1/artifact_verification.json) checked
the received file hashes, the original/exported learned states and a complete
replay of 21,723 image results. The exact original split is also included.
Historical paths in the recorded JSON files describe the original run.
